# Heart Disease Prediction using Machine Learning

## Overview
A machine learning web application that predicts the likelihood of heart disease using patient clinical data. The application provides an interactive interface built with Streamlit and compares multiple machine learning models.

## Features
- Heart disease prediction
- Interactive Streamlit interface
- Multiple ML models
- Performance comparison
- Visualization of prediction probabilities

## Technologies
- Python
- Streamlit
- Scikit-learn
- XGBoost
- Pandas
- NumPy
- Matplotlib

## Machine Learning Models
- XGBoost
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Decision Tree

## Performance Metrics
- Accuracy
- Precision
- Recall
- F1-score
